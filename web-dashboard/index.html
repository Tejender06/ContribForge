ContribForge System Architecture

1. Test-Driven Agentics (TDA) ContribForge guarantees that any defect is confirmed with an empirical failing reproduction test (Red Check) before authoring the surgical AST patch. It then re-tests reproduction (Green Check) and executes the full test suite to guarantee 0 regressions.
2. TrueForge Pause Barrier (HITL Gate) Before making any irreversible change (pushing commits or opening a public Pull Request), execution pauses at an approval barrier, allowing human inspection of the AST diff.
3. Hermetic Sandboxing All tests and code modifications run inside isolated sandbox workspaces with path containment checks, preventing accidental changes to production code.
